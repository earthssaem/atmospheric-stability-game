# 뭉게의 하늘 여행 🌤

고등학교 지구시스템과학 **「대기 안정도와 강수」** 단원(단열 변화 · 상승 응결 고도 · 푄/높새바람 · 대기 안정도)을
하나의 스토리로 학습하는 **조작형 어드벤처 게임**입니다.

동해 바다에서 태어난 공기 요정 **뭉게**를 손가락으로 끌어 태백산맥을 넘어 영서 지방까지 데려다 주세요.
**이야기의 진행이 곧 학습의 진행**입니다. (플레이 분량 25~30분, 고2 수업용)

## 실행

`index.html` 파일 하나를 브라우저에서 열면 끝입니다. 외부 라이브러리·이미지·음원 파일이 없습니다
(그래픽 SVG/Canvas, 사운드 Web Audio API 생성). 태블릿 **가로 화면 전용**이며 터치·마우스 모두 지원합니다.

- 저장은 **세션 내 이어하기만** 지원합니다. 새로고침하면 처음부터 시작합니다. (localStorage 등 브라우저 저장소 미사용)
- 소리는 HUD 우측 위 버튼으로 끌 수 있습니다. (교실 동시 사용 대비)

## 챕터 구성

| # | 장 | 학습 내용 |
|---|---|---|
| 0 | 프롤로그 | 드래그 튜토리얼, 출발 조건 (20℃ / 이슬점 12℃) |
| 1 | 첫 비행 | 건조 단열 감률 −10℃/km, 이슬점 감률 −2℃/km — 1.0km 존에서 3초 유지 |
| 2 | 구름 옷 | 상승 응결 고도 H = ⅛(T−Td) = 1.0 km, 응결 |
| 3 | 태백산맥의 벽 | 습윤 단열 감률 −5℃/km (감률 변화 배지), 정상 2.0km 도달 |
| 4 | 비를 뿌려라 | 리듬 탭 미니게임 — 강수와 숨은열 방출 (20노트 중 14 성공) |
| 5 | 산 너머로 | 하강 시 +10℃/km 승온, 부드러운 착지 |
| 6 | 뜨거워진 뭉게 | 출발/도착 비교 + 높이–온도 그래프 리플레이 = 푄(높새바람) |
| 7 | 에필로그 | 감률 γ 슬라이더 자유 실험 — 절대 안정 / 조건부 / 절대 불안정 |

하트 5개를 여정 전체에서 공유하며, 0이 되면 해당 챕터를 처음부터 다시 도전합니다(하트 회복).

## 난이도 조정 (교사용)

`index.html` 상단의 **`CONFIG` 객체** 숫자만 바꾸면 됩니다.
목표 존 오차, 유지 시간, 리듬 판정 창(ms), miss 허용 횟수, 착지 허용 속도 등이 모두 모여 있습니다.
과학 수치(감률, 응결 고도 공식)는 그 아래 `PHYSICS` 블록에 있으며 교과서 값이므로 변경하지 마세요.

## 테스트

물리 계산이 교과서 값과 일치하는지 검증합니다 (`index.html`의 PHYSICS 블록을 그대로 추출해 실행):

```bash
node tests/physics.test.mjs
```

검증 케이스: 0.5km→15℃/11℃ · 1.0km→10℃=10℃(응결) · 2.0km→5℃ · 하강 후 지표→25℃/9℃ · 안정도 경계(γ 5/10).
