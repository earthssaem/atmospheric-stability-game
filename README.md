# 뭉게의 하늘 여행 🌤

고등학교 지구시스템과학 **「대기 안정도와 강수」**(교과서 p.92~96: 단열 변화 · 상승 응결 고도 · 푄/높새바람 · 대기 안정도)를
**뭉게의 여행을 따라가며 공기의 변화를 이해하는 이야기 중심 학습 웹앱**입니다.

뭉게는 **수증기를 품은 공기 덩어리**입니다. 반투명한 몸이 바로 그 공기이고, 포화되면 몸 **안에** 물방울이 생겨 구름처럼 보입니다
(뭉게가 구름으로 ‘변하는’ 것이 아님). 학생은 뭉게와 함께 이동하며 변화를 관찰하는 동행자입니다.

각 장면의 흐름: **이야기 상황 → 짧은 조작 → 눈에 보이는 변화 → 뭉게의 반응 → 필요한 설명 → 다음 이야기**.
시간 제한·박자 맞추기·정밀 착지·반복 점수 같은 별도의 미니게임은 없고, 조작이 서툴러도 이야기는 그대로 이어집니다.

## 실행

`index.html` 파일 하나를 브라우저에서 열면 됩니다. 외부 라이브러리·이미지·음원 파일이 없습니다
(그래픽 Canvas/SVG, 사운드 Web Audio API 생성). 가로·세로 화면, 터치·마우스·키보드를 모두 지원합니다.
글꼴(제목 Jua — Google Fonts, 본문·수치 Pretendard — jsDelivr)만 인터넷에서 불러오며, 없으면 기기 기본 글꼴로 보입니다.

- **이 기기의 브라우저에 진행 상황이 저장됩니다.** (진행 장면 · 관찰 기록 · 예상 · 소리/대사/움직임 설정만 — 개인정보 입력 없음, 서버 전송 없음)
  새로고침해도 처음 화면의 **이어 하기**로 저장된 장면의 처음부터 다시 시작합니다. 기록은 ⚙️ 설정에서 지울 수 있습니다(확인 후).
- 소리 없이도 끝까지 진행할 수 있습니다 (오른쪽 위 🔊).

## 처음 화면

**처음 시작** · **이어 하기**(저장된 진행이 없으면 꺼짐) · **장면 선택**(1부·2부 처음부터, 원하는 장면) · **교사용 보기**.
저장된 진행이 있을 때 처음 시작을 누르면 지우기 전에 확인합니다.

## 1부 · 산을 건너는 뭉게 — 산을 넘은 뒤 왜 더 따뜻하고 건조해졌을까?

출발 20℃ · 이슬점 12℃ · 0 km (상대 습도 약 60%). 하나로 이어진 길(영동 바다 → 산비탈 → 정상 2 km → 영서 들판)을 따라갑니다.

| 장면 | 짧은 조작 | 눈에 보이는 변화 · 반응 |
|---|---|---|
| 0 출발 · 바람이 밀어 올려요 | [⬆ 조금 더 올라가기] (0.5 km에서 멈춤) | 몸이 조금씩 커지고 기온이 내려감, ‘처음 크기’ 점선 → “어? 몸이 좀 커졌는데?” |
| 1 구름이 시작되는 곳 | **예상**(기온 = 이슬점 직전) → 오르기 | 1.0 km에서 기온 = 이슬점 → 몸 안에 물방울 → “잠깐, 내 안에 작은 물방울이 보여!” |
| 2 구름 속으로 · 정상까지 | 산비탈을 따라 오르기 | 팽창은 계속되지만 1 km에 5℃만 식음 → 응결열 |
| 3 구름 속 들여다보기 | [🌧 물방울 지켜보기] | 물방울이 자라 비로 떨어짐(영동 쪽 비탈), 몸 안 물방울 0 |
| 4 산 너머로 내려가기 | **예상**(같은 높이로 내려가기 전) → [⬇ 조금 더 내려가기] | 몸이 작아지고 따뜻해짐, 1 km에서 15℃ (올라갈 때 10℃) |
| 5 도착 · 처음과 비교 | — | 출발과 도착을 그래프와 함께 나란히 → 푄 · 높새바람 |
| 6 관측소 보고 | 그림 Ⅲ-13 빈칸(선택) | 구간별 공기 상태·단열 변화·기온·이슬점·상대 습도 정리 |
| 7 다른 조건의 여행 (선택) | 이슬점·산 높이 바꿔 보내기 | 비교표: H = (20 − 이슬점)/8, 포화 구간, 도착 기온 (목표 과제 없음) |

## 2부 · 놓아주면 어디로 갈까? — 같은 공기를 올렸다 놓았는데 왜 다르게 움직일까?

1부의 도착 상태가 아니라 **출발 조건(20℃ · 12℃)으로 돌아온 새 실험**임을 장면·대사로 밝힙니다.
짧은 관찰: 손(외부 작용)으로 높이까지 올리기 → **같은 높이에서 뭉게 기온과 주위 기온 비교** → **예상**(놓아주기 전) → [🖐 놓아주기] → 움직임 관찰 → 반응.
같은 조건으로 [↺ 다시 해 보기]는 언제든 할 수 있고(진행 조건 아님), 움직이는 방향과 ‘뜨려는/가라앉으려는 힘’(같은 높이의 두 기온 차)을 구별해 보여 줍니다.

| 장면 | 실험 | 확인하는 것 |
|---|---|---|
| 8 대기 A (4℃/km) | 0.5 km에서 놓기 | 15℃ < 18℃ → 돌아옴 (“방금 출발했는데 벌써 돌아왔네.”) |
| 9 대기 C (12℃/km) | 같은 0.5 km | 15℃ > 14℃ → 계속 올라감 |
| 10 대기 B (8℃/km) | 1 km · 2 km | 구름이 생기는 높이(1 km) ≠ 스스로 오르기 시작하는 높이(약 1.67 km, 자유 대류 고도) |
| 11 이름 붙이기와 구름 | 관찰 뒤 설명 | 절대 안정 · 조건부 불안정 · 절대 불안정, 층운형 · 적운형 |
| 12 새로운 하늘 · 대기 D | 26℃ · 18℃ · 9℃/km, 1 km · 2 km | 같은 높이의 두 기온으로 움직임 예상 → 확인 |

2부를 마치면 **2부 자유 실험**(감률·놓는 높이를 바꿔 이름과 결과 바로 확인)을 열 수 있습니다.

## 질문과 피드백

- 질문(예상)은 결정적인 순간에만 나옵니다: ① 기온과 이슬점이 같아지기 직전 ② 같은 높이로 내려가기 전 ③ 2부에서 놓아주기 전.
- 틀려도 감점 없이 그대로 진행하고, 관찰 직후 뭉게가 예상과 관찰을 한 줄로 이어 줍니다
  (예: “같은 높이로 돌아왔는데 기온은 달라졌네. 올라갈 때와 내려올 때 기온이 변한 과정을 비교해 보자.”).
- 긴 설명은 처음 한 번만 나오고, 다시 방문하면 한 줄 요약과 **설명 다시 보기 ▸**로 바뀝니다.

## 뭉게의 크기 (팽창·수축) — 모식 표현

- 크기는 **현재 상태에서 바로 계산**됩니다: 부피 비 `V/V0 = (T/T0)·(p0/p)`(기압 p = 1013·e^(−h/8.4) hPa)를
  `TUNING.mungge.exaggerate`(기본 8)배 과장한 ‘보이는 부피’의 **세제곱근**이 반지름 배율입니다. 그래서 오르는 동안 연속으로 커지고,
  머무르면 그대로, 응결 뒤에도 계속 커지며, 내려오면 작아지고, 도착하면 처음과 거의 같아집니다(더 따뜻해 아주 조금 큼).
- 화면 전체를 확대하지 않고 몸만 변합니다. 얼굴·글자·수치·배경 축척은 그대로입니다. 부피 숫자는 화면에 보여 주지 않습니다.
- 화면에 “크기 변화는 이해를 돕기 위한 모식 표현”이라고 함께 표시합니다. 실제로는 2 km에서 부피가 약 1.2배로 훨씬 조금 커집니다.
- **속 들여다보기**(모식도): 공기 알갱이 수는 그대로이고 간격만 달라집니다. 수증기(작은 동그라미)와 물방울(파란 방울, 수증기가 모인 것)을 모양으로 구별합니다.

## 교과서 모형과 가정

- 건조 단열 감률 10℃/km, 습윤 단열 감률 5℃/km, 불포화 상승 시 이슬점 −2℃/km, 불포화 하강 시 +2℃/km.
- 상승 응결 고도 `H(km) = (T₀ − Td₀) / 8`. 물방울·구름 표현은 실제로 기온 = 이슬점(포화)일 때만 나타납니다.
- **풍상측 강수 → 풍하측 불포화 하강**(그림 Ⅲ-13): 커진 물방울은 영동 쪽 비탈에 비로 떨어지고, 남은 물방울도 떨어졌다고 단순화해
  정상에서부터 불포화 상태로 내려갑니다(증발 장면 없음).
- 상대 습도 = 이슬점의 포화 수증기압 / 기온의 포화 수증기압 × 100 (마그누스 근사식). 응결한 수증기 비율은 포화 혼합비 감소로 계산합니다.
- 2부의 운동 판정은 **놓은 높이에서 공기 덩어리와 주위 기온의 비교**입니다. 화면 위쪽에 닿았는지는 판정에 쓰지 않습니다.
  ‘팽창해서 올라간다’가 아니라 ‘같은 높이의 주위보다 따뜻해 밀도가 작아서 올라간다’로 설명합니다.

## 화면 · 조작 · 접근성

- 위: 장면 이름(🏠 누르면 확인 후 처음 화면) · 📒 관찰 기록 · ⚙️ 설정 · 🔊 소리 / 고정된 관찰값(고도·기온·이슬점, 1부 상대 습도·2부 주위 기온).
  가운데: 장면 · 발자국 그래프(접기·크게 보기) / 아래: 대사와 주요 버튼 하나.
- 조작: 뭉게를 손가락·마우스로 끌기, **[조금 더 올라가기]를 누르고 있기**, 톡 누르기(조금씩 저절로), 키보드 **↑/↓ 누르고 있기**·Enter.
- 대사: 탭·Enter·Space·→ 다음(타이핑 중 탭하면 문장 전체), ← 앞 대사. 자동으로 넘어가지 않습니다.
  ⚙️에서 **대사 표시 보통 · 빠르게 · 바로 표시**, **움직임 줄이기**를 고를 수 있습니다.
- **📒 관찰 기록**: 여정 지도(번호) · 기록 목록(출발 · 응결 시작 · 산 정상 · 하강 후 도착 · 안정도 비교 …, 값과 한 줄 설명) ·
  발자국 그래프(번호 점을 누르면 그때의 기록) · 내 예상 · 대사 다시 보기. 대화 중에 열고 닫아도 진행 상태가 그대로입니다.
- 그래프: 현재 점, 현재 높이 안내선, 구름 시작 표시, 기온(오를 때 실선 · 내려올 때 긴 점선), 이슬점(점선, 겹쳐도 보이게) — 색과 선 모양을 함께 씁니다.
- 세로 화면·휴대폰에서도 그대로 진행합니다(처음 화면에 ‘가로로 돌리면 더 넓게’ 안내만). 브라우저 확대를 막지 않습니다.
- 다른 탭으로 가면 시간·소리가 멈춥니다. 창 크기가 바뀌어도 뭉게의 위치·크기는 상태에서 다시 계산되어 튀지 않습니다.

## 교사용

- 처음 화면의 **교사용 보기**: 장면 바로 열기, 핵심 설명 다시 보기(단열 팽창 · 상승 응결 고도 · 응결열 · 응결과 강수 · 푄 · 대기 안정도 · 자유 대류 고도),
  지금 장면 처음부터, 학습 기록. 서버·계정 없이 이 기기에서만 동작합니다.
- 주소 옵션: `index.html?ch=N`(1~12 — 1~7 = 1부, 8~12 = 2부) → 처음 화면에 ‘N장부터 시작’, `?part=2` → 2부부터, `?debug=1` → 장면 상태(고도·기온·부피 비·반지름 배율·물방울 수) 표시.
- 중간 장면부터 열면 앞 장면의 기록은 회색 **‘앞선 여정 요약’**으로 표시해 직접 관찰한 기록과 구별합니다.
- **학습 기록**(1부·2부 끝, 📒): 장면별 처음 예상 · 관찰한 값 · 예상과 관찰 비교, **다시 보기 ▶**.
- 수업 예시(2차시): 1차시 — 1부(0~6) / 2차시 — 다른 조건의 여행(선택) 또는 2부(`?part=2`).
- 조작 빠르기·크기 과장 배수는 `index.html` 위쪽 `TUNING`, 과학 수치는 그 아래 PHYSICS 블록(교과서 값)에 있습니다.
