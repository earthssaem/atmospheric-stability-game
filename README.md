# 뭉게의 하늘 여행 🌤

고등학교 지구시스템과학 **「대기 안정도와 강수」**(교과서 p.92~96: 단열 변화 · 상승 응결 고도 · 푄/높새바람 · 대기 안정도)를
**관찰하고, 그 값을 근거로 판단하며** 이야기를 진행하는 조작형 어드벤처 게임입니다.

뭉게는 **수증기를 품고 있는 공기 덩어리**를 의인화한 캐릭터이고, 학생은 뭉게와 함께 이동하며 상태를 관측하고
도착 상태와 움직임을 예상하는 동행자입니다. 교사가 전자칠판에 띄워 함께 진행하거나, 학생이 컴퓨터·태블릿에서 직접 플레이할 수 있습니다.

## 실행

`index.html` 파일 하나를 브라우저에서 열면 됩니다. 외부 라이브러리·이미지·음원 파일이 없습니다
(그래픽 SVG/Canvas, 사운드 Web Audio API 생성). **가로 화면 전용**이며 터치·마우스·키보드를 모두 지원합니다.
글꼴(Jua, Gowun Dodum)만 Google Fonts에서 불러옵니다 — 인터넷이 없으면 기기 기본 글꼴로 보이고 게임은 그대로 동작합니다.

- 학습 기록(예상·관측·판단)은 **현재 브라우저 화면에만** 남습니다. 서버·계정·localStorage를 쓰지 않으며, 새로고침하면 사라집니다.
- 소리 없이도 본편 전체를 진행할 수 있습니다. (HUD 오른쪽 위 🔊 버튼)

## 구성: 두 부

| 구성 | 중심 질문 | 학습 내용 |
|---|---|---|
| **1부 · 산을 건너는 뭉게** | 산을 넘은 뒤 왜 더 따뜻하고 건조해졌을까? | 단열 변화 · 상승 응결 고도 · 높새바람 |
| **2부 · 놓아주면 어디로 갈까?** | 같은 공기를 올렸다 놓았는데 왜 다르게 움직일까? | 주위 기온 비교 · 대기 안정도 · 구름 발달 |

처음 화면에서 1부·2부를 고르거나 **챕터 고르기**로 원하는 장부터 시작할 수 있습니다. 1부는 관측소 보고 뒤
**1부 정리 지점**에서, 2부는 마지막 장 뒤 **학습 기록**에서 자연스럽게 멈출 수 있습니다.

### 1부 · 산을 건너는 뭉게 (출발 20℃ · 이슬점 12℃ · 0 km · 상대 습도 약 60%)

영서 관측소의 부탁("산을 넘은 뒤 얼마나 따뜻하고 건조해질지 알려줄 수 있을까?")으로 출발합니다.

| 장 | 학생이 하는 일 | 핵심 판단 |
|---|---|---|
| 프롤로그 · 관측소의 부탁 | 뭉게를 짧게 움직이고 출발 상태 기록 | — |
| 첫 관측 · 어느 값이 더 내려갈까? | 0.5 km 관측 지점까지 올리기(자동 정지) | 기온(−5℃)과 이슬점(−1℃) 중 더 크게 감소한 값 |
| 구름이 시작되는 곳 | 🚩 깃발로 예상 높이 표시 → 올라가며 관찰(1.0 km에서 자동 정지·물방울) | 그래프에서 두 선이 처음 만나는 점 → H = (T₀ − Td₀)/8 |
| 정상으로 · 똑같이 식을까? | 바람길을 따라 정상 2 km까지 | 그래프에서 기온이 덜 내려간 구간(1~2 km) → 응결열·습윤 단열 |
| 구름 속 관찰 · 비가 내리면? | 돋보기로 응결 → 성장·강수 → 수분 막대 관찰 | 비가 내린 뒤 함께 넘어가는 수분(줄었다) |
| 산 너머로 · 도착하면 몇 ℃? | 도착 기온 예상 → 하강(1.0 km에서 멈춰 관찰) → 착지 | 정상→1 km 동안 기온 +10℃, 이슬점 +2℃ |
| 관측소 보고 | 보고 문장 채우기(기온 +5℃, 이슬점 −3℃) | 더 따뜻해진 근거 구간 선택 + 그림 Ⅲ-13 핵심 빈칸 4개 |
| 다른 조건의 여행 | 푄 실험실 3단계 + 자유 실험 | 한 조건씩 바꾼 두 결과 비교 → 이유 |

푄 실험실: **① 같은 산, 다른 공기**(이슬점 8℃ vs 16℃) → **② 같은 공기, 다른 산**(0.8 · 1.0 · 2.5 km —
응결 고도에 못 미침과 정상에서 막 포화를 구별) → **③ 목표 상태 만들기**(도착 30℃) → 자유 실험.
결과에는 `H = (20 − 이슬점)/8`, `포화 상태로 오른 구간 = 산 높이 − H`, `도착 − 출발 = 5 × 포화 구간`이 함께 나옵니다.

### 2부 · 놓아주면 어디로 갈까? (다시 출발 조건 20℃ · 12℃)

1부의 도착 상태(25℃ · 9℃)가 아니라 **출발 조건으로 돌아가** 주위 대기만 바꾸는 새 실험임을 화면과 대사로 밝힙니다.
들어 올리는 동안은 ✋ **외부 작용**, 놓은 뒤의 운동은 **같은 높이의 두 기온 비교**로 정해집니다.

| 장 | 실험 | 확인하는 것 |
|---|---|---|
| 대기 A (4℃/km) | 0.5 km까지 올려 비교 → 예상 → 놓기 | 15℃ < 18℃ → 돌아옴 |
| 대기 C (12℃/km) | 같은 0.5 km | 15℃ > 14℃ → 계속 올라감 |
| 대기 B (8℃/km) | 1 km(응결, 10℃ < 12℃)와 2 km(5℃ > 4℃) 두 높이 | 구름이 생기는 높이(1 km) ≠ 스스로 오르기 시작하는 높이(약 1.67 km) |
| 이름 붙이기와 구름 | 관찰한 A·B·C를 감률 5·10과 비교해 이름 | 절대 안정 · 조건부 불안정 · 절대 불안정, 층운형 · 적운형 |
| 새로운 하늘 | 처음 보는 대기 D(26℃ · 18℃ · 9℃/km) | 같은 높이 두 기온으로 운동 예상 → 확인 |

안정도 이름은 관찰 뒤에 붙입니다. 2부 결과 화면의 **🔬 2부 자유 실험**에서는 감률(경계 5·10의 중립 포함)과
놓는 높이를 바꾸며 이름과 결과를 바로 확인할 수 있습니다.

## 각 장의 학습 흐름

상황 → **예상**(틀려도 감점 없음, 정답은 관찰 뒤에) → 조작·관측 → **장면 멈춤**(필요한 수치만 강조) →
**관측값·그래프를 근거로 판단** → 뭉게가 관찰과 개념을 짧게 연결 → 여정 지도·관측 기록에 남기기.

- **판단이 진행 조건**입니다. 조작 성공만으로 다음 장으로 넘어가지 않습니다.
- **예상 돌아보기**: 고른 답에 따라 다시 볼 근거를 안내하고(예: "출발과 같은 기온이 될 거라고 예상했구나. 올라갈 때와
  내려올 때, 1 km마다 변한 기온이 같았는지 그래프를 다시 볼까?"), **🔍 근거 다시 보기**로 해당 그래프 구간을 바로 엽니다.
  **✍ 관찰한 값으로 생각 고치기**도 학습 결과로 기록됩니다.
- **큰 발자국 그래프**: 관측 단계에서 확대해 점·구간을 고릅니다. 터치 오차는 가까운 점으로 보정하고,
  표시 수치는 실제 데이터 위치와 같습니다. 옆의 작은 장면이 고른 지점을 여행 위치로 함께 보여 줍니다.
- 중간 장부터 시작하면 앞 장 기록은 회색 **‘앞선 여정 요약’**으로 표시해 직접 관측한 기록과 구별합니다.

## 교과서 모형과 가정

- 건조 단열 감률 10℃/km, 습윤 단열 감률 5℃/km, 불포화 상승 시 이슬점 −2℃/km, 불포화 하강 시 +2℃/km.
- 상승 응결 고도 `H(km) = (T₀ − Td₀) / 8`. 물방울·구름 표현은 실제로 기온 = 이슬점(포화)일 때만 나타납니다.
- **풍상측 강수 → 풍하측 불포화 하강**(교과서 그림 Ⅲ-13): 물방울 일부가 비로 떨어져 영동 쪽에 남고,
  산을 넘는 공기는 정상에서 곧바로 불포화 상태로 내려간다고 단순화합니다. 그래서 하강하는 뭉게에게는 물방울을 그리지 않습니다.
- 상대 습도 = 이슬점의 포화 수증기압 / 기온의 포화 수증기압 × 100 (포화 수증기압은 마그누스 근사식).
- 2부의 운동 판정은 **놓은 높이에서 공기 덩어리와 주위 기온의 비교**입니다. 화면 위쪽(약 3 km)을 넘으면
  "화면 위로 계속 올라가요"로만 표시하며, 화면 끝에 닿았는지는 판정에 쓰지 않습니다.

## 조작 · 접근성

- 드래그 대신 **▲▼◀▶ 버튼**이나 **화살표 키**로도 움직일 수 있습니다. 급한 드래그는 이동 속도 보조로 부드럽게 따라갑니다.
- 3장 바람길을 벗어나면 감점 없이 바람길로 되돌리고, 5장 착지는 영서 평지 어디든 성공입니다(손을 떼도 천천히 내려감).
- 키보드: **Enter·Space·→** 다음 대사, **←** 앞 대사, **숫자 키** 선택지, Tab·Enter 버튼.
- 대화창의 **◀ 앞 대사**, **더 알아보기 ▸**(긴 설명), HUD의 **📒**(관측 기록·이 장의 대사 다시 보기).
- 맨 위 진행 표시(🏠 장 이름)를 누르면 확인 창 뒤 처음 화면으로 갑니다(기록 유지, 이어하기).
- 태블릿을 세로로 돌리거나 다른 탭으로 가면 시간·소리가 멈추고, 창 크기가 바뀌어도 관찰 위치가 유지됩니다.
- **하트는 선택형 막간 놀이**(구름 속 관찰 뒤 “내리는 빗방울의 박자를 따라 연주하기”)에서만 씁니다.
  학습 진행·결과 평가와 무관하고, 언제든 본편으로 돌아올 수 있습니다.

## 교사용

- 주소 옵션: `index.html?ch=N`(1~12 — 1~7 = 1부, 8~12 = 2부) → 처음 화면에 'N장부터 시작' 버튼, `?part=2` → 2부부터,
  `?debug=1` → 막간 놀이 박자 로그.
- **📒 학습 기록**(처음 화면·1부/2부 끝): 장별로 처음 예상 · 관측한 값 · 내가 고른 근거 · 생각 변화(관찰 뒤 고침)를 보여 주고,
  **다시 보기 ▶**로 해당 장을 다시 엽니다. 학생 화면을 보며 이해 정도를 파악할 수 있습니다.
- 수업 예시(2차시): 1차시 — 1부(프롤로그~관측소 보고) → 1부 정리 지점 / 2차시 — 다른 조건의 여행 또는 2부(`?part=2`).
- 난이도·조작 보조 수치는 `index.html` 위쪽 `TUNING`, 과학 수치는 그 아래 PHYSICS 블록(교과서 값)에 있습니다.

## 테스트

```bash
npm test            # 물리 단위 테스트 (index.html의 PHYSICS 블록을 그대로 추출해 실행)
npm install         # (선택) playwright 설치 후
npm run test:e2e    # headless Chromium으로 1부·2부를 끝까지 진행하며 판정·피드백·기록·보조 기능 검증
```

- `VIEWPORT=1024x768 npm run test:e2e`처럼 화면 크기를 바꿔 돌릴 수 있고, `SHOTS=폴더`를 주면 주요 장면 스크린샷을 저장합니다.
- 시스템 크로미움을 쓰려면 `CHROMIUM_PATH=/path/to/chrome npm run test:e2e`.
