# 뭉게의 하늘 여행 🌤

고등학교 지구시스템과학 **「대기 안정도와 강수」** 단원(단열 변화 · 상승 응결 고도 · 푄/높새바람 · 대기 안정도)을
하나의 스토리로 학습하는 **조작형 어드벤처 게임**입니다.

동해 바다에서 태어난 공기 요정 **뭉게**를 손가락으로 끌어 태백산맥을 넘어 영서 지방까지 데려다 주세요.
**이야기의 진행이 곧 학습의 진행**입니다. (플레이 분량 25~30분, 고2 수업용)

## 실행

`index.html` 파일 하나를 브라우저에서 열면 끝입니다. 외부 라이브러리·이미지·음원 파일이 없습니다
(그래픽 SVG/Canvas, 사운드 Web Audio API 생성). 태블릿 **가로 화면 전용**이며 터치·마우스 모두 지원합니다.
글꼴(Jua, Gowun Dodum)만 Google Fonts에서 불러옵니다 — 인터넷이 없으면 기기 기본 글꼴로 보이고 게임은 그대로 동작합니다.

- 저장은 **세션 내 이어하기만** 지원합니다. 새로고침하면 처음부터 시작합니다. (localStorage 등 브라우저 저장소 미사용)
- 소리는 HUD 우측 위 버튼으로 끌 수 있습니다. (교실 동시 사용 대비)

## 챕터 구성

| # | 장 | 학습 내용 |
|---|---|---|
| 0 | 프롤로그 | 드래그 튜토리얼, 출발 조건 (20℃ / 이슬점 12℃) |
| 1 | 첫 비행 | 건조 단열 감률 −10℃/km, 이슬점 감률 −2℃/km — 1.0km 존에서 3초 유지 |
| 2 | 구름 옷 | 상승 응결 고도 H = ⅛(T−Td) = 1.0 km, 응결 |
| 3 | 태백산맥의 벽 | 습윤 단열 감률 −5℃/km (감률 변화 배지), 정상 2.0km 도달 |
| 4 | 비를 뿌려라 | 리듬 탭 미니게임 — 강수(비로 수증기 덜어내기). 20노트 중 14 성공, 박자 없이 마구 누르면 miss |
| 5 | 산 너머로 | 하강 시 +10℃/km 승온, 부드러운 착지 |
| 6 | 뜨거워진 뭉게 | 출발/도착 비교(기온·상대 습도 60%→36%) + 그래프 리플레이 + **교과서 그림 Ⅲ-13 표 채우기** = 푄(높새바람) |
| 7 | 푄 실험실 | 출발 이슬점·산 높이를 바꾸고 도착 기온 **예측 → 확인** (미션 3개). 도착 기온 상승 = 5 × (산 높이 − 상승 응결 고도) |
| 보너스 | 하늘의 성격 | 대기 안정도(교과서 다음 차시) — 감률 γ 슬라이더 자유 실험. 완주 화면의 '보너스' 버튼 또는 `?ch=8` |

하트 5개를 여정 전체에서 공유하며, 0이 되면 해당 챕터를 처음부터 다시 도전합니다(하트 회복).

## v2 추가 기능

**단열 팽창·압축 크기 연출** — 뭉게의 몸이 고도에 따라 실제로 커지고 작아집니다
(지표 1.0배 → 정상 2km에서 1.35배, `TUNING.mungge`로 조절). 빠르게 상승하면
볼이 빵빵해지는 '부풀기' 표정과 (( )) 팽창선, 빠르게 하강하면 꾹 눌린 표정과
» « 압축선이 나타나고, 몸도 살짝 늘어나거나 납작해집니다.

**발자국 그래프** — "내 조작 = 그래프 위의 움직임"

- 우하단 상시 미니 그래프(1·2·3·5장 표시, 접기 버튼 ▾/▸): 축 고정 0~30℃/0~2km,
  기온(주황 실선)·이슬점(파랑 점선) 발자국이 도달 최고 고도까지 누적되고, 현재 위치 점 2개가
  드래그를 실시간으로 따라갑니다. 응결 지점(10℃, 1.0km) 도달 후 ✨ 마커 유지.
- 하강(5장)은 별도 색(분홍)으로 기록되어 상승 경로와 갈라지는 것이 보입니다.
- 발자국은 챕터 이동·재시작(하트 0)에도 유지됩니다 (학습 기록).
- 막간 여정 지도는 2단(좌: 지도, 우: 누적 그래프)으로, 방금 지나온 구간을 펄스로 강조하고
  한 줄 캡션을 보여줍니다 (교사 설명용).
- 엔딩 그래프는 기온+이슬점 리플레이와 "간격 8℃ → 16℃" 결론으로 발자국의 완성판이 됩니다.

**리듬 게임 박자 동기화(4장)**

- `begin()`에서 기준 시각 t₀ 하나를 정해 BGM 박 0, 카운트인, 노트 스케줄이 모두 같은
  그리드에서 출발합니다. 노트가 판정선에 닿는 시각마다 킥(쿵)이 정확히 울립니다.
- 첫 노트 전 4박 카운트인: 박자에 맞춘 틱 4번 + 화면 "4·3·2·1".
- `TUNING.ch4.pattern` — 박 오프셋 배열로 리듬 패턴 조절(0.5 = 반박자). 기본은 불규칙 패턴.
- `TUNING.ch4.audioOffset`(초) — 태블릿 오디오 지연(50~150ms)을 숫자 하나로 보정.
- 음소거 상태에서도 같은 클록으로 동작해 시각 리듬만으로 플레이 가능합니다.
- `index.html?debug=1`로 열면 4장 시작 시 콘솔에 노트별 "킥 시각 = t₀+(카운트인+오프셋)×박" 동기 로그가 출력됩니다.
- 미리 예약한 '쿵'·카운트 틱은 재도전·장 이동·처음 화면 이동 때 모두 취소됩니다(이전 판 소리가 새 판과 겹치지 않음).

## v1.4 교과서(p.92~94 단열 변화 · 상승 응결 고도 · 푄) 연계

- **상대 습도·공기 상태 계기판**: 고도·기온·이슬점에 더해 상대 습도(%)와 '불포화/포화 상태' 표시.
  경로를 따라 60% → 77% → 100% → 100% → 59% → 36% (그림 Ⅲ-13의 '증가 / 일정(100%) / 감소').
  포화 수증기압은 마그누스 근사식, 상대 습도 = 현재 수증기압(이슬점의 포화 수증기압) / 포화 수증기압 × 100.
- **먼저 예측하기(1·2·3·5장)**: 플레이 전 3지선다 예측 → 직접 확인 → 여정 지도에서 '내 예측 → 실제' 비교.
  오답 보기는 흔한 오개념(이슬점도 10℃/km, 내려올 때 5℃/km, 산을 넘으면 원래 기온으로)으로 구성.
  2장 질문은 '간격 8℃가 1 km에 8℃씩(10−2) 줄어든다' → H = ⅛(T − Td)를 외우지 않고 이해하게.
- **교과서 용어 카드**: 장을 마칠 때마다 건조 단열 감률 · 이슬점 감률 · 상승 응결 고도 · 포화 상태 ·
  습윤 단열 감률 · 응결열(숨은열) · 강수 · 단열 압축 · 푄 · 높새바람을 쉬운 말과 연결해 보여 줌.
- **그림 Ⅲ-13 표 채우기(6장)**: 3구간 × 5항목(공기 상태 / 단열 변화 / 기온 변화 / 이슬점 변화 / 상대 습도)을
  카드로 채움. 틀리면 그 행의 힌트, 3번 틀리면 '정답 보기'.
- **푄 실험실(7장)**: 고정 시나리오(20℃/12℃/2 km)를 넘어 조건을 바꿔 도착 기온을 예측·확인.
  산이 상승 응결 고도보다 낮으면 구름이 안 생겨 푄이 없음(도착 = 출발)까지 발견하게.
- **비가 내리는 시점**: 3장에서 응결 고도 위로 오르는 동안 영동 쪽 비탈에 비가 내림(교과서 p.94).
  4장은 '남은 물방울까지 비로' — 응결열은 비가 아니라 응결할 때 나온다는 점을 대사로 정리.
- **내려올 때 10℃/km인 이유**: 압축으로 데워져 곧바로 불포화 상태(물방울은 이미 비로 떨어짐)라고 설명.
- 대기 안정도(교과서 7차시)는 본 여정에서 **보너스**로 이동. 6장에 높새바람의 농작물 피해 추가.

수업 예시(2차시): 1차시 — 도입 질문 → 0~2장 → p.92~93 정리 / 2차시 — `?ch=3` → 3~6장 → 그림 Ⅲ-13 → 푄 실험실.

## v1.3 수업 운영 · 다듬기

- **처음 화면으로**: 맨 위 가운데 진행 표시(🏠 장 이름)를 누르면 확인 창 → 처음 화면. 하트·발자국은 그대로이고,
  **이어하기**로 그 장 처음부터 돌아옵니다. 확인 창이 떠 있는 동안 게임(4장 리듬 포함)은 멈춥니다.
- **차시 분할**: `index.html?ch=5`처럼 열면 처음 화면에 **5장부터 시작** 버튼이 생깁니다(1~8, 7 = 푄 실험실, 8 = 보너스).
  앞 장의 발자국 그래프·여정 지도 라벨은 끝낸 것처럼 채워집니다. 저장소 없이 주소만으로 동작합니다.
- **세로로 돌리면 일시 정지**: 회전 안내가 떠 있는 동안 시간·소리가 멈춰 하트가 깎이거나 노트가 지나가지 않습니다.
- **화면 크기 변화 대응**: 분할 화면·창 크기 변경에도 뭉게의 고도·위치가 그대로 유지됩니다.
- **4장 연타 방지**: 빗방울이 없을 때 누른 탭도 miss(`TUNING.ch4.emptyTapMiss`, 끄려면 `false`). 카운트인 중 탭은 감점 없음.
- **과학 표현 다듬기**: 4장 게이지를 '비 내리기 게이지'로(숨은열은 응결 때 나옴), 1장 단열 팽창 설명을
  "열을 썼다" → "주위 공기를 밀어내느라 에너지를 썼다"로, 5장 하강 속도는 km/s 숫자 대신 막대로,
  보너스(대기 안정도) 층운은 응결 고도 위에 그리고, 조건부 불안정일 때 γ에 맞는 **자유 대류 고도**(γ=8 → 1.7 km)를 안내합니다.
- **푸터**: 처음 화면·완주 화면 아래에 제작자 표시와 '연경쌤의 지구과학 실험실 둘러보기 →'(새 탭) 링크.

## 난이도 조정 (교사용)

`index.html` 상단의 **`TUNING` 객체** 숫자만 바꾸면 됩니다.
목표 존 오차, 유지 시간, 리듬 판정 창(ms)·패턴·오디오 지연 보정, miss 허용 횟수, 빈 탭 miss 여부, 착지 허용 속도 등이 모두 모여 있습니다.
과학 수치(감률, 응결 고도 공식)는 그 아래 `PHYSICS` 블록에 있으며 교과서 값이므로 변경하지 마세요.

## 테스트

물리 계산이 교과서 값과 일치하는지 검증합니다 (`index.html`의 PHYSICS 블록을 그대로 추출해 실행):

```bash
npm test            # 물리 단위 테스트 (의존성 없음)
npm install         # (선택) playwright 설치 후
npm run test:e2e    # headless Chromium 으로 전 챕터 관통 + 개선 사항(예측·용어 카드·그림 Ⅲ-13 표·푄 실험실·연타·홈·?ch=) 검증
```

E2E 는 시스템 크로미움을 쓰려면 `CHROMIUM_PATH=/path/to/chrome npm run test:e2e` 로 지정할 수 있습니다.

검증 케이스: 0.5km→15℃/11℃ · 1.0km→10℃=10℃(응결) · 2.0km→5℃ · 하강 후 지표→25℃/9℃ · 안정도 경계(γ 5/10)
· 발자국 경로(maxUpAlt=1.5 → (20,0)→(10,1)→(7.5,1.5), 이슬점선 합체 · 하강 (5,2)→(25,0)/(9,0))
· 자유 대류 고도(γ=8 → 5/3 km, γ=10 → 1.0 km, γ≤5 → 없음, γ>10 → 0)
· 상대 습도(20/12 → 60%, 응결 고도·정상 100%, 도착 25/9 → 36%) · 푄 왕복(20/16/2.5 km → 30℃, 산 < H → 도착 = 출발, ΔT = 5(M − H)).
