# 뭉게 유니버스 — 대기 안정도와 강수 🌤

고등학교 지구시스템과학 **「대기 안정도와 강수」** 단원(단열 변화 · 상승 응결 고도 · 푄/높새바람 · 대기 안정도)을
학습하는 교육용 게임 시리즈입니다. 세계관·그림체·물리 엔진을 공유합니다.

| 파일 | 게임 | 형태 |
|---|---|---|
| `index.html` | **뭉게의 하늘 여행** | 스토리 어드벤처 (25~30분) |
| `sky-village.html` | **모구모구 하늘마을** | 스테이지 클리어형 미니게임 모음 (6스테이지) |

# 모구모구 하늘마을 🏡

폭신폭신 하늘 마을의 솜뭉치 동물 친구 6마리의 고민(의뢰)을, 플레이어(학생)가 **공기를 다루는 기술**로
하나씩 해결해 주는 **스테이지 클리어형 미니게임 모음**입니다. 공기 요정 뭉게는 길도우미(규칙 설명·힌트)를 맡습니다.

`sky-village.html` 하나를 브라우저에서 열면 실행됩니다 (외부 라이브러리·이미지·음원 없음, 태블릿 가로 화면 전용,
localStorage 등 브라우저 저장소 미사용 — 세션 메모리만).

## 월드·스테이지

| 월드 | 스테이지 | 친구 | 의뢰 | 개념 |
|---|---|---|---|---|
| 월드1 오르내림의 기술 | S1 | 🐰 이슬토끼 초롱이 | 더위 탈출 (공기 드래그 온도 만들기 ×3) | 단열 팽창/압축 ±10 ℃/km |
| | S2 | 🦔 고슴도치 가시롱 | 숨은열 스위치 ON/OFF 비교 실험 + 퀴즈 | 감률이 다른 이유(숨은열) |
| 월드2 구름과 산의 기술 | S3 | 🐱 구름냥 몽실이 | 구름 침대를 지정 높이에 (1.0→2.0→1.5 km) | H = ⅛(T−Td) |
| | S4 | 🐿️ 다람쥐 도토리 | 산 넘기 바람 배달 주문서 3장 (26 ℃ / 비 없이 / 최고온·건조) | 푄 현상 |
| 월드3 하늘 읽기의 기술 | S5 | 🦉 부엉이 박사 | 하늘 감정사 시험 3과목 (감정 / 층운 설계 / 조건부 적운) | 대기 안정도·부력 |
| | S6 | 🐻 곰돌이 뭉뭉이 | 잔치 구름 장식 주문 3장 (층운 카펫 / 적운 풍선 / 2 km 적운) | 구름 형태 종합 |

## 게이미피케이션

- **호감도**: 동물마다 하트 0~5 (성공 +1, 노미스 보너스 +1, 실패 −0.5). 만렙 시 비밀 한마디 해금
- **스탬프 수첩**: 미션 1개 = 발바닥 스탬프 1개, 총 17개 (S1×3, S2×2, S3×3, S4×3, S5×3, S6×3)
- **동물 도감**: 클리어한 친구 등록 + 개념 한 줄 요약(= 개념 정리 노트). 6/6 완성 시 금장
- **콤보·칭찬 팝업**, **뭉게의 단계적 힌트**(2연속 실패 후 탭, 노힌트 배지), **마을 꾸미기 보상**(클리어마다 장식 추가),
  **칭호 5종**(숨은열 박사 / 구름 장인 / 바람 배달왕 / 하늘 감정사 / 마을의 영웅), 오르골풍 Web Audio BGM·효과음

## 난이도 조정 (교사용)

`sky-village.html` 상단 **`TUNING` 객체**에 미션 목표값·허용 오차·호감도 증감량이 모여 있습니다.
과학 수치는 `PHYSICS` 블록(교과서 값)이므로 변경하지 마세요.

## 테스트

```bash
node tests/village.test.mjs   # 모구모구 하늘마을 물리 검증 (34케이스)
node tests/physics.test.mjs   # 뭉게의 하늘 여행 물리 검증
```

검증 케이스: 상승 0.5 km→T₀−5 ℃ · H에서 기온=이슬점 · H 초과 −5 ℃/km · 숨은열 OFF 가상 세계 −10 ℃/km 유지
· 푄 (20 ℃/14 ℃, 산 2 km → 도착 26.25 ℃ / H≥산이면 도착=출발) · 안정도 경계(γ 5/10)
· 부력 (γ=8, 지표 30/22 → 0.5 km 복귀, 2 km 강제 상승 후 자유 상승) · 구름 형태(층운/적운/없음).

# 뭉게의 하늘 여행 🌤

동해 바다에서 태어난 공기 요정 뭉게와 함께하는 **조작형 스토리 어드벤처 게임**입니다.

동해 바다에서 태어난 공기 요정 **뭉게**를 손가락으로 끌어 태백산맥을 넘어 영서 지방까지 데려다 주세요.
**이야기의 진행이 곧 학습의 진행**입니다. (플레이 분량 25~30분, 고2 수업용)

## 실행

`index.html` 파일 하나를 브라우저에서 열면 끝입니다. 외부 라이브러리·이미지·음원 파일이 없습니다
(그래픽 SVG/Canvas, 사운드 Web Audio API 생성). 태블릿 **가로 화면 전용**이며 터치·마우스 모두 지원합니다.

- 저장은 **세션 내 이어하기만** 지원합니다. 새로고침하면 처음부터 시작합니다. (localStorage 등 브라우저 저장소 미사용)
- 소리는 HUD 우측 위 버튼으로 끌 수 있습니다. (교실 동시 사용 대비)

## 챕터 구성

| # | 장 | 학습 내용 |
|---|---|---|
| 0 | 프롤로그 | 드래그 튜토리얼, 출발 조건 (20℃ / 이슬점 12℃) |
| 1 | 첫 비행 | 건조 단열 감률 −10℃/km, 이슬점 감률 −2℃/km — 1.0km 존에서 3초 유지 |
| 2 | 구름 옷 | 상승 응결 고도 H = ⅛(T−Td) = 1.0 km, 응결 |
| 3 | 태백산맥의 벽 | 습윤 단열 감률 −5℃/km (감률 변화 배지), 정상 2.0km 도달 |
| 4 | 비를 뿌려라 | 리듬 탭 미니게임 — 강수와 숨은열 방출 (20노트 중 14 성공) |
| 5 | 산 너머로 | 하강 시 +10℃/km 승온, 부드러운 착지 |
| 6 | 뜨거워진 뭉게 | 출발/도착 비교 + 높이–온도 그래프 리플레이 = 푄(높새바람) |
| 7 | 에필로그 | 감률 γ 슬라이더 자유 실험 — 절대 안정 / 조건부 / 절대 불안정 |

하트 5개를 여정 전체에서 공유하며, 0이 되면 해당 챕터를 처음부터 다시 도전합니다(하트 회복).

## v2 추가 기능

**단열 팽창·압축 크기 연출** — 뭉게의 몸이 고도에 따라 실제로 커지고 작아집니다
(지표 1.0배 → 정상 2km에서 1.35배, `TUNING.mungge`로 조절). 빠르게 상승하면
볼이 빵빵해지는 '부풀기' 표정과 (( )) 팽창선, 빠르게 하강하면 꾹 눌린 표정과
» « 압축선이 나타나고, 몸도 살짝 늘어나거나 납작해집니다.

**발자국 그래프** — "내 조작 = 그래프 위의 움직임"

- 우하단 상시 미니 그래프(1·2·3·5장 표시, 접기 버튼 ▾/▸): 축 고정 0~30℃/0~2km,
  기온(주황 실선)·이슬점(파랑 점선) 발자국이 도달 최고 고도까지 누적되고, 현재 위치 점 2개가
  드래그를 실시간으로 따라갑니다. 응결 지점(10℃, 1.0km) 도달 후 ✨ 마커 유지.
- 하강(5장)은 별도 색(분홍)으로 기록되어 상승 경로와 갈라지는 것이 보입니다.
- 발자국은 챕터 이동·재시작(하트 0)에도 유지됩니다 (학습 기록).
- 막간 여정 지도는 2단(좌: 지도, 우: 누적 그래프)으로, 방금 지나온 구간을 펄스로 강조하고
  한 줄 캡션을 보여줍니다 (교사 설명용).
- 엔딩 그래프는 기온+이슬점 리플레이와 "간격 8℃ → 16℃" 결론으로 발자국의 완성판이 됩니다.

**리듬 게임 박자 동기화(4장)**

- `begin()`에서 기준 시각 t₀ 하나를 정해 BGM 박 0, 카운트인, 노트 스케줄이 모두 같은
  그리드에서 출발합니다. 노트가 판정선에 닿는 시각마다 킥(쿵)이 정확히 울립니다.
- 첫 노트 전 4박 카운트인: 박자에 맞춘 틱 4번 + 화면 "4·3·2·1".
- `TUNING.ch4.pattern` — 박 오프셋 배열로 리듬 패턴 조절(0.5 = 반박자). 기본은 불규칙 패턴.
- `TUNING.ch4.audioOffset`(초) — 태블릿 오디오 지연(50~150ms)을 숫자 하나로 보정.
- 음소거 상태에서도 같은 클록으로 동작해 시각 리듬만으로 플레이 가능합니다.
- 4장 시작 시 콘솔에 노트별 "킥 시각 = t₀+(카운트인+오프셋)×박" 동기 로그가 출력됩니다.

## 난이도 조정 (교사용)

`index.html` 상단의 **`TUNING` 객체** 숫자만 바꾸면 됩니다.
목표 존 오차, 유지 시간, 리듬 판정 창(ms)·패턴·오디오 지연 보정, miss 허용 횟수, 착지 허용 속도 등이 모두 모여 있습니다.
과학 수치(감률, 응결 고도 공식)는 그 아래 `PHYSICS` 블록에 있으며 교과서 값이므로 변경하지 마세요.

## 테스트

물리 계산이 교과서 값과 일치하는지 검증합니다 (`index.html`의 PHYSICS 블록을 그대로 추출해 실행):
